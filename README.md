# Raz Balin

Senior Doctoral Researcher, Castrén Lab, University of Helsinki.

I specialize in longitudinal, awake in vivo electrophysiology, run wearable-physiology measurement and biomarker
extraction, and build the analysis and statistical frameworks that turn raw signals into defensible evidence.

## Code

- [Jove_plv_pipeline](https://github.com/RazBalin/Jove_plv_pipeline): phase-locking value and pairwise phase consistency
  for complex-wavelet LFP and ECoG recordings, with edge-wise group statistics and synthetic-signal tests.
- [ProtectiveDMN_Cap](https://github.com/RazBalin/ProtectiveDMN_Cap): an open-hardware, 3D-printable cap for the resealable
  chronic head mount, with tuned print settings.
- [ephy_spatial_fidelity-toolkit](https://github.com/RazBalin/ephy_spatial_fidelity-toolkit): checks that chronic
  electrodes have not moved between sessions, from the Neuropixels current-source-density profile and the ECoG
  sagittal-sinus trough, without imaging or histology.
- [Acoustic_EMI_Detector](https://github.com/RazBalin/Acoustic_EMI_Detector): Goertzel-algorithm DSP that turns the four
  microphones of the Even Realities G2 glasses into a live mains-hum analyzer on the display.
